# dsh-task-status v0.3.1

Date: 2026-08-24

本版本发布完整的后台任务状态插件, 提供任务监控, 输出 tail 和原生终止确认.

## Highlights

- 在对话输入区上方显示后台任务状态和进度.
- 展开任务后查看输出 tail, 并保留可回看的滚动区域.
- 通过原生确认对话框安全终止后台任务.

## Features

- Node 端提供任务列表, 输出读取和终止路由.
- Client 端提供任务状态条, 展开详情和任务取消操作.

## Upgrade Notes

1. 确认运行环境为 Node >=22.19.0 和 DSH >=0.1.0-rc.5.
2. 安装插件后重新加载 DSH plugin.
3. 启动后台任务, 验证状态条, 输出 tail 和终止确认均可用.
